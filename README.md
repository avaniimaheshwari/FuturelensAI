# 🚀 FutureLens AI

### *Don’t just invest. Predict your future wealth.*

FutureLens AI is an AI-powered financial intelligence platform that transforms how users consume business news and make investment decisions.

---

## 🌍 Problem

* Business news in 2026 is still static and generic
* Same content for all users, no personalization
* 95% of Indians lack a financial plan
* Financial advisors cost ₹25,000+/year and are inaccessible

---

## 💡 Solution

FutureLens AI combines:

* 📊 Investment simulation
* 🌍 Real-time inflation data
* 📰 Global news aggregation
* 🧠 AI-driven insights

👉 Turning passive news into **actionable financial intelligence**

---

## ✨ Key Features

### 🔮 Investment Prediction

* Calculates future and real value
* Adjusts for inflation
* Supports SIP, FD, Crypto

---

### 🌍 Country-Aware Intelligence

When user changes country:

* Inflation updates ✔
* News updates ✔
* Charts adapt ✔
* AI insights change ✔

---

### 📊 Strategy Comparison

* SIP vs FD vs Crypto
* Visual comparison using charts

---

### 🧠 Scenario Analysis

* Recession → best strategy
* Normal → balanced strategy
* Boom → aggressive strategy

---

### 📰 Smart News Engine

* Aggregates top financial news
* Performs sentiment analysis
* Connects macro events to investment impact

---

### ⚡ AI Experience

* “Simulate & Analyze” flow
* Real-time data rendering
* Dynamic insights

---

## 🏗️ Tech Stack

* Frontend: React + Tailwind CSS + Chart.js
* Backend: FastAPI
* APIs: News API, Inflation API

---

## ⚙️ Setup Instructions

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8001
```

### Frontend

```bash
cd frontend
npm install
npm start
```
